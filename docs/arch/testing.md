# Testing

_GrandForge reference. Load this file only when working in this area; see [CLAUDE.md](../../CLAUDE.md) for the routing table._

Vitest runs in the **node** environment (`vite.config.ts` test config) — only pure-logic units (`frontend/src/**/*.{test,spec}.ts` + `backend/**/*.{test,spec}.ts` + `scripts/**/*.{test,spec}.ts`; the `include` is an array, add to it rather than replacing it). WASM/worker glue and browser-dependent code are excluded (`*.browser.test.ts`) and are not covered by `npm test`. When adding logic to `reviewUtils.ts` / `EngineManager.ts` pure functions, add or update adjacent `*.test.ts` files such as `frontend/src/utils/reviewUtils.test.ts`. Do not put new tests under `frontend/src/**/__tests__/`; that path is ignored by git in this repo. Tests must never write to the real database — the explorer ingest smoke test once left 15 synthetic rows in `chess-analyzer.explorernodes`; use `--dry-run`, or clean up explicitly.

**Playwright E2E** (`tests/e2e/`, config `playwright.config.ts`, run `npm run test:e2e`) — **local-only, deliberately git-ignored** (commit `67f6ab2` removed them from the repo; they are not distributed). If the files are missing from disk, restore them with `git checkout 67f6ab2^ -- playwright.config.ts tests/`. The arrow assertions in `tests/e2e/helpers.ts` target the custom overlay (`.gf-arrow-svg polygon.gf-arrow-shape`, hex8 fills prefixed `#2fc85a`/`#1f9d4d`), not react-chessboard's old stroke-based arrows. The suite covers what unit tests can't: the real Stockfish WASM engine and the review pipeline in a Chromium browser. The config's `webServer` boots the Vite **dev** server itself (no API/MongoDB needed — the engine and review run in-browser; the review's `/api` cache fetch fails over to WASM). Specs: `smoke` (load + `crossOriginIsolated` + board), `analysis` (move → eval → depth → MultiPV line count → fixed-depth terminates), `infinite` (depth blows past the fixed cap and keeps running, then Stop/Resume), `review` (short game → per-player accuracy). Tests drive deterministic moves via zustand stores exposed on `window` by `frontend/src/devHooks.ts`, which `main.tsx` imports **only** under `import.meta.env.MODE === 'development'` (see the `NODE_ENV` note in Environment notes for why not `DEV`). `tests/**` is outside the `tsc` include, so Playwright type-checks its own specs.
